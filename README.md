# Summer School on Sanskrit Computational Linguistics

Website for the Summer School on Sanskrit Computational Linguistics, jointly organised by:

- **Centre of Digital Humanities, Manipal Academy of Higher Education (MAHE), Bengaluru**
- in association with **IIT Kharagpur**

## Structure

A single-page site (`index.html`) with tabbed navigation:

- **Home** — hero introduction and dates
- **About** — purpose, format, and audience
- **Schedule** — day-by-day programme
- **Speakers** — faculty and resource persons
- **Registration** — fees, eligibility, application form
- **Resources** — preparatory reading and tools
- **Contact** — organisers and enquiries

No build step is required — open `index.html` in any browser, or deploy directly via GitHub Pages.

## Placeholders to be replaced

- `logo-slot` divs in the header — drop in the MAHE Bengaluru and IIT Kharagpur logos
- Speaker cards (`speaker-card`) — names, photos, affiliations
- Email addresses and phone numbers in the Contact tab
- Final dates and venue once confirmed

## Editing

All content lives directly inside `index.html` — find the section by its tab id (`#about`, `#schedule`, etc.) and edit the text in place.

## Local preview

Just double-click `index.html`, or run any static server in this folder.
